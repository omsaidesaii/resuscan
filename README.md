# 🎓 Resuscan

A smart platform to **track your job applications** and get **AI-powered
feedback** on resumes. Built with **React**, **TypeScript**, and
**TailwindCSS**, it provides a seamless way to upload, manage, and
analyze your resumes.

## 🚀 FEATURES

-   🔐 Authentication with secure redirects
-   📂 Upload and manage multiple resumes
-   🤖 AI-powered resume feedback & scoring
-   📊 Resume tracking & application status
-   🎨 Modern responsive UI with TailwindCSS
-   ⚡ Real-time resume loading with animated loaders

## 🛠️ TECHNOLOGIES USED

-   React
-   TypeScript
-   TailwindCSS
-   React Router
-   Zustand (via custom `usePuterStore`)
-   KV Storage API

## 🔧 HOW TO USE

1.  Clone the repository:

    ``` bash
    git clone https://github.com/yourusername/resuscan.git
    ```

2.  Navigate into the project directory:

    ``` bash
    cd resuscan
    ```

3.  Install dependencies:

    ``` bash
    npm install
    ```

4.  Run the development server:

    ``` bash
    npm run dev
    ```

5.  Open in your browser:

        http://localhost:5173

### **CUSTOMIZATION**

-   Update `/components/Navbar.tsx` to match your branding.
-   Modify `/lib/puter.ts` for authentication and KV storage
    configuration.
-   Replace `/images/bg-main.svg` and `/images/resume-scan-2.gif` with
    your own assets.
-   Adjust Tailwind classes in components for different themes or
    layouts.
